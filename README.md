# 3D Rubik's Cube

ブラウザで動く、3Dルービックキューブ風デモです。  
マウスやタッチでキューブ全体を回転し、ボタンで各面の回転・シャッフル・リセットができます。

## 特徴

- 3x3x3 のキューブを JavaScript で動的生成
- マウス操作とタッチ操作の両方に対応
- U / D / L / R / F / B の面回転ボタンを搭載
- Shuffle ボタンでランダム回転
- Reset ボタンで初期状態に復帰

## 動作環境

- モダンブラウザ（Chrome, Edge, Firefox など）

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. index.html をブラウザで開きます。

ローカルサーバーを使いたい場合（任意）:

1. プロジェクトフォルダで以下を実行
   python -m http.server 8000
2. ブラウザで http://localhost:8000 を開く

## 操作方法

- ドラッグ操作: キューブ全体の視点を回転
- U / D / L / R / F / B ボタン: 対応する面を 90 度回転
- Shuffle: ランダムに 20 手回してシャッフル
- Reset: 配置と視点角度を初期状態に戻す

## ファイル構成

- index.html: 画面構造とボタン配置
- style.css: 3D 表示、配色、レイアウト
- script.js: キューブ生成、回転ロジック、入力処理

## 実装概要

- キューブは 27 個の小キューブ（キューブレット）で構成
- 各キューブレットの位置と向きを配列で管理
- 面回転時は対象レイヤーを抽出して、座標と回転行列を更新
- 見た目は CSS の translate3d と行列変換を組み合わせて反映

## カスタマイズのヒント

- 色変更: style.css の :root 変数（--color-u など）を編集
- サイズ変更: --cube-size を調整
- シャッフル手数: script.js 内の 20 を変更
